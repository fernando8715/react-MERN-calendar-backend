# Backend con MERN - en la app Calendar

Backend creado para la aplicación de Calendar, utilizando MERN, en el curso de React con 
Fernando Herrera en la plataforma Udemy.

# instalación de desarrollo

1. instalar las dependencias con `npm install`
2. clonar el archivo `.env.template` y renombrarlo a `.env`
3. cambiar las variables de entorno de acuerdo a tu configuracion
4. corre el servidor con `npm start`
